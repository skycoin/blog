一、总说明

术语

testnet => mainnet

node => visor

manager => hypervisor

manager board => hypervisor board

manager web interface => hypervisorUI


Skywire的主网Mainnet文档正在不断改进，并将不时更新，以包括更多的细节和解释功能。你可以日常在Skycoin的Github库内，Skywire-Mainnet readme和Skywire-Mainnet wiki中找到相关文档：https://github.com/SkycoinProject/skywire-mainnethttps://github.com/SkycoinProject/skywire-mainnet/wiki


你还可以在GitHub上找到关于Skywire Mainnet规则的相关文章：https://github.com/SkycoinProject/skywire-mainnet/blob/master/mainnet_rules.md


从Skywire testnet到Skywire mainnet的迁移期将持续两个月，从4月开始，到5月底结束。（注意：一旦迁移周期结束，Skywire Testnet将被关闭，如果您在此之前没有迁移，您将不会继续收到奖励。）迁移期间的奖励将通过添加Skywire testnet 和 mainnet参与的正常运行时间来处理。每个奖励类别（官方矿机、DIY矿机）的Skycoin奖励总额，参见上文所提的Skywire Mainnet的规则文章。


奖励池的大小不变，这意味着官方和DIY矿机奖励类别的Skycoin池的大小，是同时与Skywire testnet和Skywire mainnet奖励相关的。官方的Skyminers（官方和官方第三批）只需要有7个节点和75%的正常运行时间，即可收到最大的奖励（每月的全额奖励）。整个升级对奖励没有任何消极影响，每个节点的奖励已经相应调整，升级后网络将会提供更大的单节点奖励。


*所有在前四周内（四月期间）成功切换到Mainnet的用户，均可获发额外津贴。申领奖金的要求是在天网干线上至少连接一个密钥，奖金的详情及确切数目将于适当时间公布。Skywire白名单系统将继续作为管理公开密码匙的管理平台。


目前Skywire主网的正常运行时间跟踪功能已经完成，前端（用户界面）的更改预计在1-2周内完成，这意味着你将能够在mainnet上查看你当前的正常运行时间。在迁移期间，将显示Skywire testnet和Skywire mainnet的正常运行时间。如果您不想在个人电脑上安装Golang语言环境，那么在本地运行hypervisor也是一个很好的选择。


优点：通过在您的个人电脑上运行它，即可管理您在全球任何地方的节点(visors)。在本地运行管理程序时，更新过程更简单。到目前为止，update函数只覆盖了必须对管理程序板进行回流的visors。


缺点：需要在您的个人电脑上手动安装管理程序。


奖励：如前所述，只有7个节点(visors)需要为正式的Skyminer所有者申请最大的奖励数量。SkywireProxy Discovery：即Skycoin的代理发现器（用户可用来搜索代理连接是否为在制品）将很快发布。此功能相当于Skywire Testnet的“搜索服务”功能。


二、Official Skyminers-官方Skyminers


官方Skyminers的更新过程非常简单。你只需要用新的Skybian images （即镜像文件）来重新刷你的SD卡即可。我们已经更新了之前的Skyflash工具，它现在叫做Skyimager。

Skyimager指南：https://github.com/SkycoinProject/skywire-mainnet/wiki/Skyimager-User-Guide


请按照上面列出的步骤来使用你的sd卡。用于查看hypervisorUI和通过SSH访问hypervisor板的端口保持不变(端口22:SSH，端口8000:hypervisorUI)注意：为了使用新的socks连接和Skychat应用程序，您必须调整Skyminer路由器的端口转发规则。操作方法和细节参见调整网络指南：https://github.com/SkycoinProject/skywire-mainnet/wiki/Networking-Guide-Official-Skyminer 


如果你忘记了整个过程，可以查看官方的Skyminer指南，通过从头开始和运行用来快速刷新，步骤如下：https://github.com/SkycoinProject/skywire-mainnet/wiki/Official-Skyminer-Guide


完成后，不要忘记更新你的注册公钥：https://github.com/SkycoinProject/skywire-mainnet/wiki/Skywire-Whitelisting-System#modify-public-keys


三、DIY Skyminers


目前，如果你的矿机不是使用orange pi prime板子，那么升级一个DIY的Skyminer可能比升级一个官方的Skyminer需要更多的努力。如果你使用的是orange pi prime板子，你可以简单地按照Skyimager指南（见上文，也可以在GitHub的wiki上找到）如果您使用的是其他板子，可能需要用Skyfleet提供的社区支持包或从源代码来安装。安装说明详见GitHub的自述文件。您需要通过SSH访问该板并执行列出的命令。


Skyfleet插件的使用说明如下：https://github.com/Skyfleet/sky-update

社区支持的其他用户指南也将陆续发布，可时常点击查看：https://skywug.net/forum/forumdisplay.php?fid=22 

 

四、官方Skyminer升级主网详细步骤（适用于官方板子或树莓派板子DIY的skyminer)

升级顺序：使用Skyimager生成镜像——刷SD卡——设置端口转发并记录IP地址——依顺序将SD插入板子并启动——IP地址+:8000登录管理界面——记录key并加入白名单。


1.使用Skyimager生成镜像：

使用带翻译功能的浏览器比如谷歌、火狐、QQ等打开网址：

https://github.com/SkycoinProject/skywire-mainnet/wiki/Skyimager-User-Guide

点击skybian发布页面：




找到最新发布的版本，下载跟自己电脑相匹配的Skyimager程序。




然后下载7zip解压工具，找到下载的Skyimager程序压缩文件，点击鼠标右键，找到7zip解压工具打开压缩包。（注意，打开后将文件多点击几下，直到出现警告页面或者设置页面为止。）

 




如果出现警告页面，点击更多信息，点仍要运行。





就会出现如下设置页面：




点击Next进入下一页，按照划横线处设置（注意，这里的设置是以在板子上运行虚拟监控程序为列，如果想在电脑上运行，请按照官方教程有关设置进行）



 

请注意，如果你是使用的树莓派板子构建的skyminer，则需要从这里https://pan.baidu.com/s/1JtgJ7FRiyCZd0SBj2w7FWg （百度云盘，提取码：8GFf ）

下载SkyRaspbian镜像文件到本地电脑，并记住文件路径，使用工具7-zip打开文件,并复制文件路径，按照下图进行选项设置。




然后点击Next进入下一页，按照图示选择：





点击页面，复制整个配置文件，新建一个文档并保存，以备用。






记住创建的镜像文件的文件路径。

至此，Skyimager程序开始构建最新的8个镜像，此过程根据你的网络速度大概1-3小时左右，完成后如下图所示：



完成后可以打开文件夹看到最新镜像，如下图：

 


1. 使用Balena Etcher工具 ：https://www.balena.io/etcher/

将镜像0-7依次刷新到Skyminer SD卡。由于此流程管理程序是运行在板子上的，所以image-0只作为管理节点存在，其key不会显示，最终管理界面只显示7个key,  与在测试网运行时有区别。








至此，已经刷好了第一张SD卡，然后换卡，点击Flash Another继续选择下一个镜像文件重复之前的步骤，刷完八张SD卡为止。


2. 设置端口转发并记录IP地址 

参考网络指南Skyminer官方：“端口转发规则”和“在家庭网络中获取IP地址”：https://github.com/SkycoinProject/skywire-mainnet/wiki/Networking-Guide-Official-Skyminer#port-forwarding-rules

 




4.将刷好的SD 卡依次插入PI板子，并逐步打开板子电源和skyminer路由器电源

5.用浏览器打开skyminer路由器IP加:8000登录管理界面，初次打开时需要点击对话框下方的英文部分设置登录密码，切记保存好密码，并使用此密码登录




 

6. 将key(节点公钥)更新到白名单。方法是，用浏览器打开白名单系统https://whitelist.skycoin.com/，将原来测试网的key删除，并从管理页面列表复制key粘贴保存即可。如果是没有参与过测试网，而是最新构建的skyminer(sky矿机)，请参照“官方白名单系统用户指南”进行设置：https://github.com/SkycoinProject/skywire-mainnet/wiki/Skywire-Whitelisting-System

7.查询key在线：用浏览器打开https://uptime-tracker.skywire.skycoin.com/visors，点击右上角三个点，找到“查找”，打开后，将key复制粘贴即可查看是否在线。

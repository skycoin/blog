### Skywire v1.3.11

Skywire v1.3.11 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.11).

- **Improved log collection** — better logic and version filtering; limited `skywire-cli log` to online visors only
- **Windows command fixes** — cleaned up Windows-specific commands
- **Survey collection verification** — changed verification of DMSG connection to survey collection verification
- **Updated DMSG dependency** — using hashicorp yamux

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

For questions or technical assistance: [t.me/skywire](https://t.me/skywire)

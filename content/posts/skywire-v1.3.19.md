### Skywire v1.3.19

Skywire v1.3.19 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.19).

- **Proxy command fixes** — fixed `proxy start` and `proxy stop` commands
- **Route tree command** — new `skywire cli rtree` command for viewing the route tree
- **DMSG client type** — added DMSG client type support
- **Updated STUN server IPs**
- **Help menu improvements**
- **Config gen fixes** — fixed offline config gen, `config gen --all`, and `config gen -pd`
- **Windows VPN fix**
- **Skychat and skysocks-client flag fixes**

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

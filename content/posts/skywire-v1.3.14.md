### Skywire v1.3.14

Skywire v1.3.14 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.14).

- **macOS installer improvements** — improved postinstall script
- **Windows archive** — added skysocks client to the Windows release
- **Package installer fix** — added missing apps to the package installer
- **New `--confpath` flag** — specify custom config path during generation
- **Improved proxy command** — `skywire-cli proxy` improvements
- **Improved uptime command** — better `skywire-cli ut` logic
- **Panic fixes** — resolved two panics in CLI commands
- **UI improvements** — rebuilt hypervisor UI with better reboot and shutdown operations
- **Rewards update** — corrected rewards cutoff date

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

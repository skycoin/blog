### Skywire v1.3.21

Skywire v1.3.21 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.21).

- **TPD concurrency** — Transport Discovery now supports concurrent operations
- **Transportability module** — new module to verify that the visor is reachable for transport creation
- **Systemd services** — added systemd unit files for service management on Linux
- **Reward System UI** — new web-based reward system interface
- **Manual transport creation** — improved logic for manual transport setup
- **Route subcommand fix** — fixed `skywire cli visor route` implementation

The minimum version requirement for mainnet rewards has been updated.

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

### Skywire v1.3.18

Skywire v1.3.18 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.18).

- **Apps use Cobra CLI** — all apps now use the Cobra CLI framework and are integrated with merged binary compilation
- **GNU-POSIX flag conformance** — apps use double-hyphenated longhand flags following the GNU-POSIX standard
- **Survey collection fix** — fixed v1.3.17 survey collection with updated DMSG deps and endpoint name change
- **Skywire-deployment archives** — added skywire-deployment release archives
- **Removed systray binary** — `skywire-systray` has been removed
- **Codebase cleanup** — removed unused parts including .appveyor.yml

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

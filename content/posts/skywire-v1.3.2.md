### Skywire v1.3.2

Skywire v1.3.2 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.2).

- **Skysocks client CLI** — new `skywire-cli skysocksc` command for controlling the SOCKS5 proxy client from the command line
- **Skysocks UI fix** — resolved display issues in the skysocks interface
- **Rebuilt UI**

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

For questions or technical assistance: [t.me/skywire](https://t.me/skywire)

### Skycoin v0.24.1

Skycoin v0.24.1 has been released and is available from [GitHub](https://github.com/skycoin/skycoin/releases/tag/v0.24.1).

- **Content-Security-Policy header** — added CSP header to HTTP responses for improved security
- **Portable browser fix** — fixed portable browser version opening to blank page

### Install

Downloads are available on the [GitHub release page](https://github.com/skycoin/skycoin/releases/tag/v0.24.1) for Linux, Windows, and macOS.

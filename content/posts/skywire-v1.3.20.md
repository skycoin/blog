### Skywire v1.3.20

Skywire v1.3.20 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.20).

This release completes the transition to a single unified binary:

- **United binary architecture** — all Skywire components now compile into a single `skywire` binary
- **VPN command fix** — fixed `skywire cli vpn`
- **Setup-node config generation**
- **App launch fixes**
- **Windows IPC fix** — resolved inter-process communication issue on Windows

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

### Skywire v1.3.3

Skywire v1.3.3 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.3).

- **UI migration** — migrated to Angular Material MDC components
- **Autopeering fix** — removed autopeering to prevent a panic
- **Skysocks client** — added `--pk` flag support to `skywire-cli skysocksc`

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

For questions or technical assistance: [t.me/skywire](https://t.me/skywire)

### Skycoin v0.28.3

Skycoin v0.28.3 has been released and is available from [GitHub](https://github.com/skycoin/skycoin/releases/tag/v0.28.3).

- **Database migration** — replaced the unmaintained boltdb with bbolt (the maintained etcd fork) for improved reliability
- **RISC-V support** — added riscv64 build target
- **Updated dependencies**

Builds are available for Linux (amd64, arm64, armhf, arm, 386, riscv64), macOS (amd64, arm64), and Windows.

### Install

Downloads are available on the [GitHub release page](https://github.com/skycoin/skycoin/releases/tag/v0.28.3).

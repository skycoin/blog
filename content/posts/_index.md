Skywire is Skycoin's decentralized mesh network: a peer-to-peer transport layer
of **visors** that form transports with one another, route traffic over
multi-hop paths, and run applications — VPN, SOCKS5 proxy, chat, file transfer —
on top of that mesh instead of on top of the public internet.

This section is the running development log for that work. Each update covers a
single day of merged changes across the [Skywire](https://github.com/skycoin/skywire)
codebase and the wider Skycoin stack — routing and transport internals, the
dmsg messaging layer, CXO object storage, the hypervisor UI, the command-line
interface, packaging and CI — with the pull request numbers behind each change.

Updates are published daily. You can follow them by
[RSS](/index.xml), or browse by
[Development](/tags/development), [Skywire](/tags/skywire) or
[Announcements](/tags/announcements).

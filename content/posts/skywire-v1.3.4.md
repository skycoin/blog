### Skywire v1.3.4

Skywire v1.3.4 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.4).

- **Encrypted surveys** — surveys are now encrypted to skycoin.asc for security
- **Improved log collection** — better log collecting logic
- **Version reporting** — visor version is now sent on uptime updates
- **UI improvements** — update options hidden from UI, various fixes

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

For questions or technical assistance: [t.me/skywire](https://t.me/skywire)

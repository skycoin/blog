### Skycoin v0.27.1

Skycoin v0.27.1 has been released and is available from [GitHub](https://github.com/skycoin/skycoin/releases/tag/v0.27.1).

This release includes Skywallet hardware wallet integration, CLI transaction encoding, and code-signed releases:

- **Skywallet integration** — hardware wallet daemon service for signing transactions
- **CLI transaction encoding** — new `encodeTransaction` command for encoding transactions
- **Code-signed releases** — daemon and standalone binaries are now code-signed for macOS
- **Improved transaction logging** — more verbose logging of transaction creation
- **Performance optimizations** — stop scanning unconfirmed transactions earlier

The Skycoin wallet is available in Electron (desktop application) and standalone (browser-based) variants.

### Install

Downloads are available on the [GitHub release page](https://github.com/skycoin/skycoin/releases/tag/v0.27.1) for Linux (x64, ARM), Windows (x64, x86), and macOS.

### Skywire v1.3.7

Skywire v1.3.7 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.7).

- **RISC-V support** — added riscv64 build target, expanding Skywire to a new architecture
- **CLI refactor** — improved command structure and usability
- **Transport logic improvements**
- **ARMv7 survey fix** — resolved survey generation on ARMv7 devices
- **Security updates** — bumped golang.org/x/text, golang.org/x/net, and golang.org/x/crypto dependencies

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

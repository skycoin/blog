### Skycoin Core

The major news this week is the launch of the new Android wallet.  Among other updates, it now includes language support for Japanese!

### Skywire Update

Skywire has now added at retry logic for application use following network error. We have also fixed certificate issues with public deployments and written more tests for dmsg.

### Skywallet Update

As well as adding firmware update functionality for the desktop wallet, Skywallet added a version endpoint to the daemon this week.

### CX Update

With the release of CX 0.7.0, we are happy to announce the addition of flags for configuring transaction and block sizes for CX Chain.

Check back soon for more news on the latest developments in these and other important areas at Skycoin!

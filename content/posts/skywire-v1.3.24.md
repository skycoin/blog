### Skywire v1.3.24

Skywire v1.3.24 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.24).

- **Survey IP fetch fix** — IP address is now fetched exclusively over DMSG for improved privacy; removed HTTP mode
- **Survey generation fix** — resolved issues with survey generation on the visor
- **Cross-platform survey fixes** — fixed survey issues on macOS and Windows
- **Reward calculation improvements** — variable initialization, context handling, and logging fixes

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

### New Reward Pool Starts in November

Skywire Rewards starting in November will be open to all architectures and operating systems.

A new reward pool of the same size as the existing reward pool will be added, specifically for x86_64 / AMD64 architecture machines, but also including 32-bit (386) .

The addition of a reward pool for x86_64 / AMD64 architecture machines should avoid a negative impact on current rewards for SBC miners.

The mainnet rules article will be updated before November with the details of this change.

### Officially Supported Platforms

The needed functionality for rewards has currently only been tested for package-based installations which are installed via the apt repository (https://deb.skywire.skycoin.com/) or the AUR (https://aur.archlinux.org/packages/skywire-bin) or when run from source on linux

For non-linux operating systems, some changes to the skywire source code may yet be required for a valid survey to be produced, which is the prerequisite for rewards.

We can only guarantee rewards for linux machines with the officially maintained packages at this time.

Going forward, we will do our best to integrate any changes necessary for windows and macOS for the production of the survey, etc. so that obtaining rewards when running skywire on one of the aforementioned operating systems will be as simple as it is with the linux packages.

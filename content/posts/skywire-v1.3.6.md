### Skywire v1.3.6

Skywire v1.3.6 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.6).

- **Nil app launcher panic fix** — resolved a crash when querying the overview API before the app launcher was initialized
- **App launcher availability check** — added safety check for app launcher state

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

For questions or technical assistance: [t.me/skywire](https://t.me/skywire)

### Skywire v1.3.10

Skywire v1.3.10 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.10).

- **New DMSG HTTP servers** — added additional dmsghttp servers for improved connectivity
- **Switched to hashicorp yamux** — replaced the outdated yamux fork with the maintained upstream version
- **Updated dependencies**

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

For questions or technical assistance: [t.me/skywire](https://t.me/skywire)

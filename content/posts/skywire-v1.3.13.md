### Skywire v1.3.13

Skywire v1.3.13 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.13).

- **Improved log command** — replaced panic with proper error handling in `skywire-cli log`
- **Improved ping output** — cleaner ping command results; removed autotransport logic from ping
- **Transport bandwidth logs fix**
- **Updated dependencies** — Go version bump, vendored dependency updates
- **Minimum version requirement** incremented to v1.3.11

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

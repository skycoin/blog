### Skywire v1.3.22

Skywire v1.3.22 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.22).

- **System monitoring** — added `gotop` as `skywire cli visor top` for real-time system stats
- **Network statistics** — version stats and DMSG client listing for uptime tracker and DMSG discovery
- **Transport tree** — improved `skywire cli tp tree` with route finding functionality
- **Reward System UI improvements** — transport setup-node request logging integrated with the reward system UI
- **Heartbeat logic** — added heartbeat for STCPR and DMSG connections to maintain persistent connectivity
- **Reward System documentation**

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

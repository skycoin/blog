### Skywire v1.3.34

Skywire v1.3.34 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.34).

This release includes platform support and release pipeline improvements. Builds are now available for Linux (amd64, arm64, armhf, arm, 386, riscv64), macOS (amd64, arm64), and Windows (amd64, arm64, 386) with native .pkg and .msi installers.

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [GitHub release page](https://github.com/skycoin/skywire/releases/tag/v1.3.34).

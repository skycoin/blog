### Skywire v1.3.5

Skywire v1.3.5 has been released and is available from [GitHub](https://github.com/skycoin/skywire/releases/tag/v1.3.5).

- **Custom apps support** — users can now run custom applications on the Skywire network
- **Log collection size limit** — prevents excessive disk usage from log collection
- **Improved survey logic**

### Install

Linux users can install Skywire from the [APT repository](https://deb.skywire.skycoin.com/) or the [AUR](https://aur.archlinux.org/packages/skywire-bin). Windows and macOS installers are available on the [Downloads](https://skycoin.com/downloads) page.

For questions or technical assistance: [t.me/skywire](https://t.me/skywire)
